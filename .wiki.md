# Project Summary
The **PersonaRewire** project is an innovative platform designed for content creators to discover, rewrite, and manage viral social media posts, particularly on Twitter and LinkedIn. It empowers users to develop unique brand voices through customizable personas and AI-driven content rewriting features. Key functionalities include tracking AI usage costs, ethical content adaptation, AI persona suggestions, and funnel stage mapping. The integration of the **X.com (Twitter) API** enhances the **Live Feed** functionality, enabling real-time monitoring and interaction with selected profiles' posts.

# Project Module Description
- **Frontend**: User interface for managing profiles, personas, and monitoring costs, including AI persona suggestions, funnel stage management, and the Live Feed feature.
- **Backend**: API services for user authentication, data storage, and AI-powered content rewriting, with endpoints for integrating the X.com API for live post monitoring.
- **Cost Tracker**: Visual analytics for monitoring AI service expenditures.
- **Rewrite Workspace**: Generates rewritten content based on original posts and selected personas, now with funnel stage guidance.
- **Profile Manager**: Manages categories and monitored profiles with bulk upload capabilities.
- **Rewrite History**: Chronological log of AI-generated rewrites with filtering and export capabilities.
- **Live Feed**: Displays recent posts from monitored X.com profiles, fetching live data from the X API v2. The header now includes status badges and buttons for scanning and clearing feeds. Recent UI updates have improved dropdown visibility and usability.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Recharts
- **Database**: PostgreSQL (managed via SQLAlchemy)
- **AI Services**: Integrated with AI models for content rewriting and persona suggestions
- **External API**: X.com (Twitter) API v2 for live post monitoring

# Usage
1. **Install Dependencies**: 
   - For the backend: Navigate to `app/backend` and run `pip install -r requirements.txt`.
   - For the frontend: Navigate to `app/frontend` and run `pnpm install`.
2. **Build the Project**:
   - For the backend: Run `python -m alembic upgrade head` to apply database migrations.
   - For the frontend: Run `pnpm run build` to build the frontend application.
3. **Run the Application**:
   - Start the backend server using `uvicorn main:app --reload`.
   - Start the frontend development server with `pnpm run dev`.
